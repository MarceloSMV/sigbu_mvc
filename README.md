Curso Analisis y Diseño de Sistemas (2025-II)
Docente: Ing. IGNACIO RUBEN TACZA VALVERDE

SiGBU es una plataforma web desarrollada para la gestión, control y transferencia de activos y bienes dentro del entorno universitario. 
El sistema permite centralizar la información de los bienes, facilitando el seguimiento de su ubicación y estado, así como la gestión de solicitudes de movimiento entre áreas.
